# iPad対応リアルタイムチャット 最小版 第1版

## 内容
- メールアドレスとパスワードによる新規登録・ログイン
- 1つの共通チャットルーム
- 過去100件の表示
- 新着メッセージのリアルタイム反映
- ログアウト
- iPad・スマートフォン対応
- RLSによる認証済み利用者限定アクセス

## ファイル
- index.html: 画面
- style.css: デザイン
- app.js: ログイン・送信・リアルタイム処理
- supabase_setup.sql: データベース作成と安全設定

## 重要
- service_role key、パスワード、回復コードは誰にも渡さないでください。
- アプリの初回設定には Project URL と Publishable key（または anon public key）だけを使います。
- この版は学習・少人数テスト用です。公開運用前に、連投制限、通報、管理者削除、利用規約などを追加してください。
